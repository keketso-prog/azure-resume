# ☁️ Azure Cloud Resume Challenge

# 🚀 Built as part of my journey toward becoming a Cloud Solutions Architect

👋 Overview

This project is a full-stack serverless resume application built and deployed on Microsoft Azure. It demonstrates my ability to design and deploy cloud-native applications using core Azure services.

# 🚀 What I Built

I built a serverless resume website with a real-time visitor counter and a fully automated deployment pipeline.

# ✨ Key Features
- Static resume website hosted on Azure Blob Storage
- Serverless backend API using Azure Functions
- Visitor tracking system using Azure Cosmos DB
- Monitoring and logging with Application Insights
- CI/CD pipeline using GitHub Actions
- 🏗️ Architecture

This project follows a fully serverless cloud architecture:

- Frontend: Azure Blob Storage (Static Website Hosting)
- Backend: Azure Functions (API layer)
- Database: Azure Cosmos DB (visitor counter)
- Monitoring: Application Insights
- CI/CD: GitHub Actions
# 🛠️ Tech Stack
Microsoft Azure (Blob Storage, Functions, Cosmos DB, Application Insights)
JavaScript / HTML / CSS
GitHub Actions (CI/CD)
# 🧠 What I Learned
- How to build serverless applications on Azure
- How to connect multiple Azure services together
- How to implement CI/CD using GitHub Actions
- How to monitor and troubleshoot cloud applications using Application Insights
- How to design cloud-native architectures
# 💡 Key Takeaways
- Built and deployed a full serverless application on Azure
- Integrated multiple cloud services into one architecture
- Automated deployment using CI/CD pipelines
- Applied cloud monitoring and observability best practices
